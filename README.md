
# Projet 4 — Étude de santé publique avec Python

## Contexte
Projet réalisé dans le cadre de ma formation Data Analyst chez OpenClassrooms.

Cette étude s'appuie sur des données de la FAO (Organisation des Nations unies pour l'alimentation et l'agriculture) pour analyser la sous-alimentation et la disponibilité alimentaire dans le monde.

## Problématique métier
Comment exploiter les données alimentaires mondiales pour mieux comprendre la sous-alimentation et identifier les principaux enjeux de sécurité alimentaire ?

## Méthodologie
1. Importation et exploration des données avec Python.
2. Vérification et préparation des jeux de données.
3. Analyse des indicateurs de sous-alimentation.
4. Étude de la disponibilité alimentaire.
5. Création de tableaux et de visualisations.
6. Présentation et interprétation des résultats.

## Compétences mobilisées
- Python
- Pandas
- Analyse exploratoire des données
- Nettoyage et préparation des données
- Visualisation de données
- Communication des résultats

## Livrables
- Notebook Python contenant les analyses.
- Notebook au format PDF.
- Présentation PowerPoint de l'étude FAO.

## Objectif professionnel
Transformer des données publiques en indicateurs compréhensibles pour faciliter l'analyse et la prise de décision.
